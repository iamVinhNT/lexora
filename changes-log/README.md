# Detailed change log

`CHANGELOG.md` giữ summary theo release. Thư mục này giữ record chi tiết cho từng thay đổi.

## Convention

```text
changes-log/[YYYY-MM-DD]/[tag]-[slug].md
```

Tags dùng trong filename:

```text
feat
fix
docs
refactor
breaking
chore
```

Mỗi record nên ghi:

- Scope thay đổi.
- Nội dung chính.
- Impact/compatibility.
- Verification nếu có.
